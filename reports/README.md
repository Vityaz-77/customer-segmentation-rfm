# reports/

Folder ini digunakan untuk menyimpan output visualisasi dan laporan dari analisis EDA.

## Isi

- `*.png` / `*.jpg` — Chart dan plot yang diekspor dari notebook
- `*.html` — Laporan interaktif (jika ada)
- `*.pdf` — Laporan dalam format PDF (jika ada)

## Catatan

File di folder ini adalah **output**, bukan input. Jangan simpan data mentah di sini.
